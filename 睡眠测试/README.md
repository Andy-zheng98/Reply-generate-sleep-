# 睡眠测试

本目录集中保存仓库中的两套睡眠模型测试，测试数据、运行脚本、原始输出、评分和实验说明分别保留在各自文件夹内。

## 1. 睡眠模型与 ChatGLM3 对比测试

目录：[`睡眠模型与ChatGLM3对比测试`](睡眠模型与ChatGLM3对比测试/)

使用相同提示词和尽可能一致的生成参数，对比原始 ChatGLM3-6B 与 Sleep LoRA checkpoint-160，包含逐题输出、性能指标、规则评分、对比表和图。

## 2. 失眠非药物专项测试

目录：[`失眠非药物专项测试`](失眠非药物专项测试/)

测试睡眠环境、音乐与声音、体操与运动、呼吸训练、多轮个体约束、长期失眠和高风险安全边界，共 20 个案例、24 个用户轮次。
