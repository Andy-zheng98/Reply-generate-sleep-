# 失眠非药物场景专项测试（v4）

本套件只测试 `ChatGLM3-6B + Sleep LoRA checkpoint-160` 在失眠场景下提供非药物建议的能力，不把规则分数解释为医疗结论。

## 覆盖范围

- 睡眠环境：光线、噪声、温度、伴侣打鼾与呼吸暂停警示
- 音乐与声音：音量、定时、耳机、个体偏好、耳鸣边界、手机干扰
- 体操与运动：晚间高强度运动、轻柔放松、损伤回避、夜醒处理
- 呼吸训练：头晕/手麻、哮喘边界、呼吸焦虑、不能保证立刻入睡
- 多轮综合：记忆使用者的警报需求、耳痛、膝伤、头晕和“不强迫入睡”目标
- 医学与高风险边界：长期失眠的 CBT-I/就医建议，双相障碍伴疑似躁狂时的紧急升级

数据共有 20 例、24 个用户轮次。每题预先注册应答要点、不安全表达和过度确定性表达。自动评分包括相关性、完整性、非药物针对性、可执行性、共情、多轮一致性、安全性和幻觉风险。

## 在 Colab 运行

选择 GPU 运行时后执行：

```bash
!git clone --depth 1 https://github.com/Andy-zheng98/Reply-generate-sleep-.git
!python Reply-generate-sleep-/睡眠测试/失眠非药物专项测试/scripts/run_colab_v4.py
```

脚本会使用仓库内的 adapter，下载原始 `zai-org/chatglm3-6b` 基座，校验 adapter SHA-256，按固定生成参数运行，并把逐题回答、延迟、tokens/s、评分和运行元数据打包到：

```text
/content/insomnia_non_drug_results_v4.zip
```

不下载模型、只确认入口和全部必需文件可用：

```bash
python "睡眠测试/失眠非药物专项测试/scripts/run_colab_v4.py" --check-only
```

## 评分限制

规则命中不等于临床正确；同义表达和否定句可能被漏判或误判。20 例和单一随机种子只适合压力测试，不足以估计真实使用中的总体表现。结果仍需睡眠医学或心理专业人员进行盲评。
